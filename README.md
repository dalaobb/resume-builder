# Resume Builder


A free privacy-first online resume builder.

Create professional resumes without registration.

No account.
No upload.
No tracking.

Everything runs locally in your browser.


---

# Features


## Resume Builder

- Edit resume information
- Real-time preview
- Switch templates
- Export PDF


## Privacy First

Your resume data never leaves your device.

No:

- Account
- Login
- Cloud storage
- Resume database


## Multi Language

# Design Philosophy

The generated resume should be:

✓ Professional

✓ Easy to read

✓ ATS compatible

✓ A4 printable

✓ Black-and-white friendly

The goal is not to create a decorative resume.

The goal is to create a resume that helps users get interviews.
